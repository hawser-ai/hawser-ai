# examples

- `try_hawser.py` — a small script that runs Hawser on your own file with your own schema or
  question (`python examples/try_hawser.py --help`). Runs from the recorded quickstart by
  default; `--live` calls a real model.

The bundled quickstart lives in the package (`hawser init` copies it out), and the reference
skill with its example pair lives in `skills/invoice-po-reconciliation/`.
